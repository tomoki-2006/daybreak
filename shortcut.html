Make it change every morning

Every Daybreak picture is named by the morning it is for, like 2026-11-18.jpg. A Shortcut with four actions reads today’s date, picks that picture and sets it as your Lock Screen. It needs no arithmetic and no deadline. Setting it up takes about five minutes, once.

The four actions

Open Shortcuts, tap +, name the shortcut Daybreak, and add these actions in order. Find each one with the search field.

  1. Date, left on Current Date.
  2. Format Date: Date Format Custom, Format String yyyy-MM-dd. The capital MM is the month; a lower-case mm would give minutes.
  3. Get Contents of URL. In the URL field, paste i/uc-transfer-app/ , then insert the Formatted Date variable and type .jpg. The field then reads i/uc-transfer-app/[Formatted Date].jpg.
  4. Set Wallpaper (listed as Set Wallpaper Photo on some versions) with the downloaded picture as input. Choose Lock Screen, tap the arrow to show more options, and turn Show Preview off. If you see Crop to Subject, turn it off too.

Tap ▶ once to test: lock the phone and this morning’s picture should be there.

The online pictures are all 1290 × 2796, the size of the larger iPhones; iOS scales them to fit other models. For a picture drawn at your phone’s exact pixel size, download it from the site or make a set in the builder and use the offline version below.

Run it every morning

iOS 27
  1. Build the shortcut above first.
  2. Open it, tap Edit › Automation, and add a Time of Day trigger: for example 6:00 AM, daily.
  3. Tap Edit › Info › Privacy and turn on Allow Running When Locked, so it can run before you unlock the phone.
iOS 26
  1. Shortcuts › Automation › +, then Time of Day: 6:00 AM, Daily.
  2. Add the four actions (or choose Run Shortcut › Daybreak).
  3. Choose Run Immediately and turn Notify When Run off.
iOS 16 to 18
  1. Shortcuts › Automation › + (on iOS 16: Create Personal Automation) › Time of Day, 6:00 AM, Daily.
  2. Run the Daybreak shortcut. On iOS 17 and 18 choose Run Immediately; on iOS 16 turn off Ask Before Running.

Lock Screen, once: touch and hold the Lock Screen › Customize, then turn off Depth Effect, the spatial scene and Perspective Zoom where they appear. Keep the clock small: on iOS 27 choose the compact clock; on iOS 26 drag the clock’s handle back up. If a Focus mode is linked to another Lock Screen, unlink it.

Offline version: pictures in iCloud Drive

Use Get File instead of the internet
  1. In the builder, tap Download days (ZIP) on your iPhone and choose the next 30 days, the next 90 days, or all days. The pictures are JPEGs named by date.
  2. In Files, tap the ZIP once to unzip it, then move the folder to iCloud Drive › Shortcuts › Daybreak. You end up with iCloud Drive › Shortcuts › Daybreak › uc-transfer-app › 2026-11-18.jpg …
  3. On iOS 18 or later, touch and hold the folder and tap Keep Downloaded, so the early-morning run works without signal.
  4. Replace action 3 with Get File: Folder Shortcuts (the default), File Path Daybreak/uc-transfer-app/[Formatted Date].jpg, and Error If Not Found on.

A 30- or 90-day ZIP runs out. The builder tells you the last date it covers: download the next set before then.

Other devices

Android

Copy the unzipped folder to phone storage, for example Pictures/Daybreak/uc-transfer-app. Use the pixel-9 or pixel-9-pro pictures from the builder.

Tasker

  1. Profile: Time, 06:00.
  2. Parse/Format DateTime: Input Type Now, Output Format yyyy-MM-dd. The result is in %formatted.
  3. Set Wallpaper with the image Pictures/Daybreak/uc-transfer-app/%formatted.jpg, Lock Screen where offered.

No app: each morning, set the picture by hand from Photos › Use as wallpaper.

Mac

Shortcuts on the Mac can set the desktop picture, which also shows behind the login screen. Use the mac-16x10 pictures, or download one for your own screen size from the start page.

macOS 26 or later: build the same four actions and add a Time of Day automation set to Run Immediately.

Older macOS: a launchd job (StartCalendarInterval Hour 6, Minute 0) that runs:

/bin/zsh -c 'F=~/Daybreak/uc-transfer-app/$(date +%F).jpg; osascript -e "tell application \"System Events\" to tell every desktop to set picture to POSIX file \"$F\""'

date +%F prints the date as YYYY-MM-DD, the same as the file names.

Windows

This script sets the desktop wallpaper. Only Enterprise and Education editions let a script set the Windows lock screen. Save it as daybreak.ps1 and use the win-16x9 pictures.

$f = "$env:USERPROFILE\Pictures\Daybreak\uc-transfer-app\$(Get-Date -Format yyyy-MM-dd).jpg"; Add-Type 'using System.Runtime.InteropServices;public class W{[DllImport("user32.dll",CharSet=CharSet.Unicode)]public static extern int SystemParametersInfo(int a,int b,string c,int d);}'; [W]::SystemParametersInfo(0x14,0,$f,3)

Schedule it:

schtasks /Create /TN Daybreak /SC DAILY /ST 06:00 /TR "powershell -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File %USERPROFILE%\daybreak.ps1"

Troubleshooting

Nothing changed in the morning
  • iOS 27: check Allow Running When Locked in the shortcut’s Info › Privacy. iOS 26 and earlier: the automation must say Run Immediately.
  • Open Set Wallpaper: Show Preview must be off.
  • The phone was off at that time. iOS doesn’t catch up on missed runs, so tap the shortcut once.
“File not found” or a 404
  • The format string must be exactly yyyy-MM-dd. Add Show Result after Format Date to check: it should read like 2026-11-18.
  • The pictures run until two weeks after the deadline. Before the start date there is no picture yet.
  • Offline version: the folder names in the path must match Files exactly, including upper and lower case, and the ZIP you downloaded may have run out.
Picture zoomed, cropped or flipping back
  • Turn off Perspective Zoom. Make sure the pictures were made for your phone size (Device in the builder). The online pictures are 1290 × 2796 and iOS scales them to fit other iPhones.
  • A Focus mode linked to another Lock Screen can make the wallpaper flip back. Unlink it.
  • An occasional “error 2” from Set Wallpaper is an intermittent iOS error. Run again, or add Wait 1 second before it.
